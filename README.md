# ⚡ CF Forge — کارخانه کانفیگ ابری

ساخت **نامحدود** کانفیگ VLESSِ واقعی و آماده‌ی اتصال با آی‌پی‌های تمیز کلادفلر — بدون نیاز به سرور شخصی. کل پروژه روی **Cloudflare Pages** اجرا می‌شود:

- 🖥️ **رابط کاربری** (همین سایت): فقط تعداد بده → کانفیگ بگیر → کپی/QR/دانلود
- ⚙️ **موتور پروکسی** (`functions/[[path]].js`): سرور VLESS روی WebSocket که کلادفلر به‌صورت خودکار دپلوی می‌کند

---

## دپلوی در ۴ قدم

### ۱) آپلود در گیت‌هاب
یک Repository جدید بساز و فایل‌ها را push کن (یا با drag & drop آپلود کن).

### ۲) اتصال به Cloudflare Pages
در `dash.cloudflare.com` برو به **Workers & Pages → Create → Pages → Connect to Git** و مخزن را انتخاب کن:

| تنظیم | مقدار |
|---|---|
| Framework preset | `Vite` |
| Build command | `npm run build` |
| Build output directory | `dist` |

روی **Save and Deploy** بزن. پوشه‌ی `functions` خودکار شناسایی می‌شود — هم سایت، هم سرور VLESS با هم بالا می‌آیند. ✅

### ۳) تنظیم UUID (خیلی مهم)
داخل پروژه‌ی Pages: **Settings → Environment variables → Production** و این متغیر را بساز:

- `UUID` = یک UUID تصادفی (دکمه‌ی 🔀 داخل سایت)

> ⚠️ بعد از ذخیره حتما از تب **Deployments** گزینه‌ی **Retry deployment** را بزن تا متغیر اعمال شود.

اگر متغیر نگذاری، UUID پیش‌فرض پروژه استفاده می‌شود:
`b3311f0d-72e4-4f9c-9a3d-5c6b7a8f9e0d`

### ۴) استفاده
1. سایت (`your-project.pages.dev`) را باز کن — دامنه خودکار پر شده است.
2. UUID همان مرحله‌ی ۳ را در فیلد «کلید UUID» بگذار.
3. تعداد را انتخاب کن و «ساخت کانفیگ» را بزن.
4. کانفیگ‌ها را کپی کن یا QR را با v2rayNG / Streisand / sing-box اسکن کن.

**لینک اشتراک خودکار:**
```
https://your-project.pages.dev/sub/YOUR-UUID
```

(اختیاری) از تب **Custom domains** دامنه‌ی شخصی وصل کن و همان را در سایت وارد کن.

## مسیر جایگزین: Worker جداگانه

اگر نمی‌خواهی Pages داشته باشی، فایل `worker.js` آماده است:

```bash
npm i -g wrangler
wrangler login
wrangler deploy worker.js --name cf-forge --compatibility-date 2025-01-01
```

بعد متغیر `UUID` را در **Settings → Variables** ورکر ست کن. آدرس ورکر (`name.workers.dev`) را در فرم سایت به‌عنوان دامنه وارد کن.

## متغیرهای محیطی

| نام | اجباری؟ | توضیح |
|---|---|---|
| `UUID` | پیشنهاد می‌شود | کلید احراز هویت VLESS (پیش‌فرض داخل کد) |
| `PROXYIP` | اختیاری | رله‌ی جایگزین `host` یا `host:port` وقتی اتصال مستقیم شکست بخورد |

## نکات

- همه‌ی کانفیگ‌ها داخل **مرورگر خودت** ساخته می‌شوند؛ چیزی به جای دیگری ارسال نمی‌شود.
- آی‌پی‌های «تمیز» فقط ورودی edge کلادفلر هستند؛ مسیر نهایی با SNI/Host به سایت تو می‌رسد.
- پلن رایگان کلادفلر: روزانه ۱۰۰ هزار درخواست — برای مصرف شخصی فراوان است.
- فقط برای استفاده‌های قانونی.
